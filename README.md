# Jazz Chord Generator

Code for my undergraduate dissertation, [Data Representations in Neural Network Based Chord Progression Generation Methods](web/paper.pdf) (University of Edinburgh, 2020). The paper compares six ways of encoding chords for neural networks that predict the next chord in a jazz progression, using 1,380 jazz standards from iReal Pro.

Try it at **[chords.felixwu.me](https://chords.felixwu.me)**: enter a progression, choose a representation and a network, and listen to what comes next.

## Web app

The site is static files in `web/`, with no build step. To run it locally:

```sh
cd web && python3 -m http.server 8765
```

Every push to `master` deploys `web/` to Firebase Hosting (see `.github/workflows/`).

The models run in the browser in plain JavaScript (`web/models.js`). The data and weights in `web/data/` are generated by two scripts:

```sh
python parseAllFiles.py        # MusicXML in dataset/xml -> dataset/parsed.json
python export_web.py           # chord vocabulary and songs -> web/data
python train_web.py encodings  # the six chord representations, including Word2Vec
python train_web.py 1he        # trains FNN, CNN and LSTM on one representation (1he, ene, wne, nne, 2he, w2v)
node check_web_models.mjs      # checks the JS models score the same as PyTorch
```

`train_web.py` needs `torch` and `gensim`. It trains at the paper's sizes and saves weights as int8, using Apple's GPU (MPS) when available.

## Command-line generator

The original command-line app suggests chords with an n-gram model and plays them:

```sh
pip install synthesizer pyaudio   # macOS: brew install portaudio first
python parseAllFiles.py
python run.py
```

On Windows, install PyAudio from the bundled wheel: `pip install .\PyAudio-0.2.11-cp39-cp39-win_amd64.whl`.

`train.py` is the original training script used for the paper.
